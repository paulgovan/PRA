This manuscript describes PRA, an R package on CRAN (v0.6.0, MIT license, DOI 10.32614/CRAN.package.PRA) that unifies quantitative project risk analysis methods under a single API: Monte Carlo/second-moment uncertainty analysis, earned value management, sensitivity and contingency analysis, noisy-OR risk inference, sigmoidal learning curves, and design structure matrices; plus a probabilistic-network extension for causal cost propagation. To my knowledge, no existing CRAN package unifies these methods.

Section 8 additionally exposes the package's functions as tools over the Model Context Protocol (MCP), enabling LLM agents to invoke these analyses directly. I've included this because reproducible tooling for agent-driven workflows is an emerging trend, but I recognize it sits slightly outside classical statistical-software territory.
